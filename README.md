# 🎯 About This Repository

This repository contains my **TypeScript learning journey**, covering concepts from the fundamentals to advanced TypeScript and practical test automation.

The goal is not just to learn TypeScript syntax, but to understand how TypeScript can be used to build:

- 🧪 Test automation frameworks
- 🌐 Web automation
- 🔌 API automation
- 🛠️ Reusable utilities
- 📦 Scalable automation architecture
- 🚀 CI/CD-ready test frameworks
